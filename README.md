# Smart AI Forms — AI Form Builder for WordPress

The only WordPress form builder that generates complete
forms from plain English prompts — no OpenAI API key needed.

## Features
- Prompt-to-form AI generation (server-side, no API key)
- Drag-and-drop form builder
- Conditional logic
- Stripe & PayPal payments
- File uploads
- AI dropdown options
